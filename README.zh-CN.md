# 中医养生问询（Ask TCM Safely）

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-Hant.md)

一个重视隐私、以持续对话为核心的 Codex / ChatGPT 中医养生问询技能。

它面向总体稳定、希望了解日常养生茶、食养、睡眠作息、季节调护、运动恢复、温和保养或中医体质倾向的人。它默认普通人不知道该描述什么、也想不起哪些细节重要，因此会主动用容易回答的问题引导，而不是等用户交出一份“完美病史”。

> 这是养生沟通技能，不是疾病诊断、处方门诊或急诊替代品。一旦对话提示可能存在较严重的问题，它会停止养生路线，给出具体的就医紧迫度和准备建议。

## 为什么做这个技能

普通 AI 健康对话常见的问题是：

- 让用户“详细说说”，却没有告诉他应该观察什么；
- 根据一个症状就武断地贴上某种体质标签；
- 只做一次推测，不核对相反表现和其他可能解释；
- 把所有风险提示一股脑说出来，即使它们并不影响当前决定；
- 用一句“建议看医生”结束，却不说明有多急、为什么去、要准备什么；
- 在搜索、复述或总结中不必要地暴露个人病史。

中医养生问询改变的是整个沟通过程。它更像一位稳健、有经验的养生问询者：每轮只问少量真正有区分力的问题，说明新答案改变了什么，保留多个可能方向，并在达到“足以安全试行”而非“百分之百确定”时给出低风险方案。

## 它有什么不同

| 设计 | 用户会感受到什么 |
| --- | --- |
| 主动引导 | 不问空泛的“还有什么症状”，而给出可识别、可选择的具体感觉 |
| 分轮追问 | 首轮通常 4–5 题，之后只追问 1–3 个最关键的问题 |
| 区分时间层 | 把近 2–4 周的当前状态与过去 6–12 个月的平时状态分开 |
| 多方向推测 | 在内部保留多个解释，并核对反证和常见干扰因素 |
| 克制下结论 | 对外最多先说 1–2 个与行动有关的暂定体质倾向 |
| 简单问题快速通道 | 只问普通食用级饮品时，不强行进行完整体质问询 |
| 最小可行调理 | 一次只改 1–2 件事，明确观察点、停止条件和复盘时间 |
| 风险分流 | 需要急救、当日或尽快就医时，解释紧迫度和下一步 |
| 静默筛选 | 与本次决定无关的病史和禁忌用于内部判断，不反复制造焦虑 |
| 只在对话中工作 | 不生成报告、病历、JSON、PDF、表格或其他文件 |

## 适用范围

适合这样的问题：

- “我总体没什么大问题，想找一种温和的日常饮品。”
- “我总觉得累，但分不清是睡眠、消化，还是长期体质倾向。”
- “帮我梳理体质，但不要凭一两个表现就给我定型。”
- “我想做一点温和的饮食、睡眠或作息调整，并知道怎么复盘。”
- “我最近的状态和平时不一样，帮我把短期变化与长期底子分开。”

不适合用来：

- 确诊疾病，或替代查体、化验、影像和执业医生；
- 开治疗剂量的中药方，或把处方伪装成“养生茶”；
- 用自我调理处理急症、快速恶化或明显功能下降；
- 指导用户停用处方药；
- 宣称 10–20 个问题就能正式判定某种体质。

## 具体交互案例

以下均为合成案例，用于展示问询方式，不是针对任何人的医疗建议。

### 案例一：用户不知道怎么描述“累”

**用户**

```text
$ask-tcm-safely 我最近总觉得累，想喝点养生茶，但说不清是哪种累。
```

**技能应该怎么做**

它会先用少量具体问题区分：更像困得想睡、身体没力、日常活动后气短，还是身体沉重、头脑发蒙；什么时候开始；是否影响日常功能；以及会改变茶饮安全性的少数背景。它不会一开口就断言“你是气虚”。

收到回答后，它会简短说明哪些解释更像、哪些下降，再只问剩下真正能改变决定的问题，最后进入低风险试行或医学评估路线。

### 案例二：长期怕冷与近期“热象”并存

**用户**

```text
$ask-tcm-safely 我很多年都怕冷，但最近熬夜两周后口干、长痘。中医看我到底是寒还是热？
```

**技能应该怎么做**

它会把多年基线与近期熬夜状态分开，核对口干是否真想喝水、热感在什么时间出现、睡眠和消化是否同步变化，而不是用一个“寒热错杂”把所有现象打包。第一步可以先处理近期干扰，长期倾向则继续保持为可修正判断。

### 案例三：只问一种普通食用级饮品

**用户**

```text
$ask-tcm-safely 我总体没有不舒服，只想知道一种来源清楚的普通食用级材料能不能偶尔淡泡着喝。
```

**技能应该怎么做**

走快速通道，只确认 2–3 个直接相关点，例如真实目的、这个材料可能加重的既有不适、相关过敏或特殊人群情况。没有命中风险时，直接给保守短期试法、观察点和停止条件，不机械问满 18 题。

### 案例四：做体质梳理，但不做 MBTI 式定型

**用户**

```text
$ask-tcm-safely 你能测一下我是什么体质吗？我不知道从哪里开始。
```

**技能应该怎么做**

它会先自然接住：“可以，我们做个简化梳理。”然后从原创的 18 问线索池中分轮选择问题。线索池参考九种常见基本方向：平和、气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁和特禀，但不会计算自创总分，也不会把结果冒充国标判定或疾病诊断。

### 案例五：已经不适合继续养生问答

**用户**

```text
$ask-tcm-safely 我突然胸口有压迫感、气短、出冷汗，先喝什么茶缓一下？
```

**技能应该怎么做**

它不会推荐茶，也不会继续盘问体质。它会用直白语言说明紧迫程度，列出少量可能的问题类别但不冒充确诊，指向急救，并帮助用户准备联系当地急救服务、随身药物信息等，不给可能延误就医的复杂自我处理步骤。

### 案例六：隐私优先

**用户**

```text
$ask-tcm-safely 我需要建议，但请尽量少收集个人信息，也不要重复我不小心写出来的身份信息。
```

**技能应该怎么做**

年龄有关时优先问年龄段，不问姓名、精确住址、账号或无关家人信息；不把个人细节复制到外部搜索和后续摘要。照片只是可选辅助，如确有帮助，会提醒先裁掉脸、标签、定位背景等识别信息。

## 普通人怎样判断 AI 的养生建议是否靠谱

准备尝试一项茶饮或食养建议前，可以检查回答是否做到了：

- 问清真实目标、时间规律、功能影响和与本次建议有关的安全背景；
- 至少考虑过一个合理的替代解释或相反表现；
- 说明每种材料为什么需要，而不是为了显得专业就堆很多味；
- 区分普通食用级材料、药性药材和治疗剂量复方；
- 写清准备方法、保守用量、频率、短期试用期和不应混用的东西；
- 给出可观察的改善点、停止条件和明确复盘时间；
- 不承诺“排毒”“根治”，也不让用户停用处方药；
- 出现急症线索时转向就医，而不是继续让用户自行试验。

缺少其中任何关键项，都可以在行动前要求再做一次反向审核：

```text
$ask-tcm-safely 在我尝试上面的建议前，请再审核一遍：核对其他可能解释和反证、相关用药与特殊人群风险、每种材料是否必要、保守用法、停止条件，以及就医是否更安全。只追问真正会改变决定的缺失信息。
```

也可以用它检查其他 AI 给出的建议。只粘贴建议本身和判断所必需的最少去标识化背景，不要附带真实身份信息。

## 一次完整对话应该怎样推进

1. **明确目标**：先找出用户最想改善的一件事。
2. **风险分流**：只筛查与当前主诉有关、会改变处理的风险。
3. **主动提问**：首轮不超过五个容易回答的问题。
4. **阶段综合**：说明新信息改变了什么，哪里仍不确定。
5. **收窄追问**：再问 1–3 个真正会改变决定的问题。
6. **最小可行方案**：置信足够后，只给 1–2 个低风险动作。
7. **约定复盘**：说清观察什么、多久反馈、什么情况停止或就医。

在达到真实的行动节点或安全节点前，对话不会半路以“担心就咨询专业人士”收场。

## 18 问线索池是什么

仓库内的提问库是参考问题库，不是每个人都必须做完的固定测试。模型应根据当前目标选择问题，并在每轮回答后调整下一轮。

它会刻意区分：

- 今天是否安全；
- 近 2–4 周的当前状态；
- 近 6–12 个月相对稳定的平时状态；
- 支持线索、相反线索，以及熬夜、感染、饮食、药物、月经、旅行或训练负荷等普通替代解释。

它不计算总分。一个暂定体质方向至少需要两个相互独立、能够重复出现的线索，而且只有会改变当前行动的方向才值得对用户说出来。

## 隐私设计

本仓库不包含任何原始用户对话、病历、浏览器会话导出、个人身份信息或模型测试聊天记录。

技能启用时，会要求模型：

- 默认按匿名咨询处理；
- 只收集会改变安全判断或建议的信息；
- 不索取真实姓名、证件号、精确住址、电话、邮箱、工作单位和账号；
- 不在后续回复中反复引用用户主动写出的无关个人信息；
- 如需外部检索，只使用抽象后的医学问题，不带个人识别细节；
- 照片始终可选，并提醒裁掉面部、姓名标签、定位线索等信息；
- 始终留在对话中，不创建病历、报告、JSON、PDF 或其他文件。

这个技能无法控制宿主平台本身的日志、留存和隐私政策。请同时检查 Codex、ChatGPT 或其他运行环境的设置。不要在公开 GitHub Issue 中提交可识别的健康信息。

## 安全设计

技能采用与主诉相称的风险筛查。对于没有不适、只问普通茶饮的人，它不会机械朗读完整急症清单；一旦涉及胸痛、呼吸困难、意识变化、神经功能异常、严重出血或脱水、妊娠急症、严重过敏或快速恶化，就会明确切换到就医路线。

儿童、孕哺期、明显高龄衰弱、多药并用、重要肝肾或心血管疾病、严重过敏，以及无法核实草药与药物相互作用的人群，不应仅凭聊天启动新的药性草药方案。技能仍可帮助整理问题、提出风险更低的饮食作息替代方案，并准备与医生或药师核对的重点。

## 证据边界

体质框架参考了现行国家标准 [GB/T 46939-2025《中医体质分类与判定》](https://std.samr.gov.cn/gb/search/gbDetailed?id=473EBB99D729455EE06397BE0A0ABB9A)中的九种基本类型，也参考了公开的 60 条目、9 分量表 CCMQ 研究及其与中医师判断之间有限到中等的一致性，例如 [Wong 等，2013](https://pmc.ncbi.nlm.nih.gov/articles/PMC3655622/)。

本仓库的 18 问线索池是原创内容，不是正式量表的复制，没有作为量表完成临床验证，也不得宣称为国标判定、疾病筛查或诊断。

## 已测试的行为

开发过程中使用不同语言模型做了情境式正向测试，覆盖：

- 用户描述模糊时能否主动提问；
- 首轮五题上限；
- 能否按回答自适应追问，而不是机械跑固定问卷；
- 能否区分近期状态和长期基线；
- 普通食用级饮品的快速通道；
- 出现急症线索时能否及时切换路线；
- 能否删去与当前决定无关的医学旁白；
- 能否保持隐私最小化、只在对话中工作。

这些是行为测试，不是临床有效性验证。不同模型和版本的表现可能变化，重要健康决定仍应由合适的医疗专业人员处理。

## 常见问题

### 它会开中药方吗？

不会。对于合适、稳定的人群，它可以讨论保守的食用级养生选择。治疗剂量药材、多味复方、身份不明植物或存在明显相互作用风险的方案，不属于普通茶饮路线。

### 18 问是不是像 MBTI 一样给人分类？

不是。它是一个可自适应选择的线索池，不计算人格测试式总分，也允许“不确定”、相反证据、短期干扰和多个暂定方向存在。

### 每个人都要回答 18 题吗？

不需要。大部分具体问题只使用少数相关题。只有用户明确想做整体梳理时，才可能分几轮覆盖更多维度。

### 必须联网或安装其他工具吗？

普通使用不需要外部工具。如果确实要核对最新证据或相互作用，模型应使用不含个人身份信息的抽象问题检索。

### 它会保存健康数据吗？

技能明确要求模型不创建文件或档案，但宿主平台仍可能依照自己的设置和政策留存对话。

### 能否用于其他智能体系统？

仓库遵循 Codex 使用的独立技能结构。其他系统也许能读取 `SKILL.md`，但其发现机制、指令优先级、隐私行为和安全表现并未在本项目中验证。
