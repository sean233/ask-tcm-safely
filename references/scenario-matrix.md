# 养生场景与就医路由

只读取匹配当前咨询的行。总体稳定时做养生问询；一旦超出养生范围，立即切换为风险解释和就医指引。

| 场景 | 优先了解 | 养生重点 | 边界 |
| --- | --- | --- | --- |
| 单纯想喝养生茶 | 目标、口味、饮食、睡眠、药物、慢病 | 食用级、少味、短期、可观察 | 不把药用复方当日常茶；不承诺治病 |
| 精力不足、工作疲劳 | 睡眠、工时、咖啡因、运动、饮食、体重、出血/慢病 | 先修睡眠与负荷，再考虑温和食养 | 持续或进行性疲劳、功能下降先排常见医学原因 |
| 睡眠保养 | 入睡/夜醒/早醒、打鼾、咖啡因、酒精、情绪、药物 | 固定起床、光照、运动、减少刺激物 | 憋醒、严重嗜睡、躁狂/自伤或显著功能损害需评估 |
| 消化保养 | 胃口、反流、腹痛、排便、体重、食物和药物 | 规律进食、纤维/水分按耐受调整 | 出血、剧痛、持续呕吐脱水、体重下降不做茶饮试验 |
| 怕冷或燥热感 | 环境、客观体温、体重、心悸、月经、药物 | 衣着环境、睡眠、饮食和活动先行 | 发热或持续全身症状不能只归寒热体质 |
| 运动与劳损恢复 | 负荷、外伤、疼痛位置、无力麻木、睡眠、营养 | 负荷管理、睡眠、渐进恢复 | 急性外伤、进行性神经症状或深色尿等需评估 |
| 季节与地域调护 | 气候、室内温湿度、过敏、皮肤/鼻咽史 | 环境控制、饮食和作息适应 | 呼吸困难、严重过敏、感染恶化先就医 |
| 病后稳定恢复 | 原诊断、是否已退离急性期、食欲体力、现用药、复诊安排 | 逐步恢复饮食活动，不急补、不多味叠加 | 复发、重新发热、气促胸痛、脱水等回医疗流程 |
| 女性周期与更年期保养 | 周期、出血量、孕育可能、潮热、睡眠、药物 | 作息、运动、饮食和症状记录 | 异常出血、妊娠可能伴痛或明显贫血表现先评估 |
| 老年养生 | 跌倒、认知、吞咽、肾功能、多药、饮食 | 简单、可进食、避免叠加补品 | 新发嗜睡、意识或步态变化，或多药相互作用需评估 |
| 慢病人群保养 | 诊断、处方药、监测、肝肾功能、医生计划 | 不改变原治疗，只做兼容的生活管理 | 不擅停药；草药茶先由医师/药师核对 |
| 儿童、孕哺、备孕 | 精确年龄/孕周、饮食、症状、药物 | 以正常饮食、睡眠和照护为主 | 不在线上设计药性茶饮或汤剂 |
| 不明草药、网购粉末、药酒 | 标签、规范名、部位、来源、剂量、反应 | 不尝味、不试用，保留包装 | 身份不明即暂停；不适按安全门分流 |
| 胸痛、气短、晕厥或神经异常 | 起病、严重度、意识、单侧症状、既往病 | 不做养生建议 | 说明可能的心肺/神经急症并按安全门求助 |
| 高热、持续呕吐、出血、剧烈疼痛 | 时间线、客观变化、饮水尿量、药物、基础病 | 不用茶饮或药膳拖延 | 指出可能感染、脱水、出血或急腹症等类别并及时就医 |
| 服茶饮/补品后出现新症状 | 产品、剂量、批次、时间线、同时用药 | 点名暂停可疑新产品并观察 | 严重过敏、呼吸/循环/神经异常立即急救；不复饮验证 |

每轮内部检查：最值得先改的一个生活因素是什么；哪个危险解释不能漏；推荐是否足够简单；是否给了停止条件；是否已经主动提出下一轮问题。
